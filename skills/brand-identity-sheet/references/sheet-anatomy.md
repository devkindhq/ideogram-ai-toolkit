# Sheet Anatomy — Named Panel Types

Pick from these when assembling a brand identity sheet prompt. Not every sheet needs
every panel — pick the ones that earn their place for the brand at hand, and add new
panel types here when a real job establishes one worth reusing.

## Wordmark card
A white or paper-toned rounded-corner UI card: small brand-name label at the top
(uppercase, small, in the ink color), the wordmark itself large and centered, a tiny
supporting line at the bottom (an "edition" tag, a price, a version label — doesn't
need to mean anything literal, it's there to read as "this is a real product card,"
not to communicate real product info). This is the panel that answers "what does the
logo look like on a clean surface, at normal UI scale."

## App-icon grid
4-8 square (occasionally one taller/wide) rounded-corner icons, each a distinct
material sample pulled from the brand's style keywords. Range matters more than
repetition — don't make six icons that are all "glowing orb, different color." A good
grid mixes:
- one gradient/glow/bioluminescent icon (organic energy)
- one texture/mesh/weave icon (technical material)
- one metallic/brushed/reflective icon (industrial material)
- one mechanical/utility icon if the brand has a technical register (gear, tool, dial)
- one character/mascot icon if the brand has one
- one abstract-pattern icon as a wildcard

Each icon is testing "does this material read as on-brand," not restating the logo.

## Pill buttons
2-3 stacked fully-rounded buttons, cycling through primary / accent / neutral-secondary
from the brand palette. This panel exists to show CTA hierarchy — which color is
"go," which is "secondary," which is "disabled/neutral" — at a glance, separate from
the logo entirely.

## Giant central wordmark
The same wordmark as the card panel, but at headline/hero scale, filling a tall
central column of the sheet. This is the type-specimen moment — it's testing whether
the wordmark holds up at scale, not just in a small card.

## Secondary lockup
Wordmark (often at a smaller, secondary scale) paired with a small geometric brand
glyph — a star, a dot-and-orbit mark, a simple shape distinct from anything in the
primary logo. This is the "what stamps a footer, a favicon-adjacent mark, a seal"
variant — it should feel like a sibling to the primary mark, not a duplicate of it.

## Character/mascot panel
Only include if the brand actually has (or wants to explore) a character — an
astronaut, a mascot, an illustrated figure. Rendered in the same material vocabulary
as the rest of the sheet (if the icon grid is glowing-cosmic, the character should be
too) so it reads as part of the same system, not a bolted-on illustration.

## Adding a new panel type
If a real job produces a panel worth reusing across brands (not just this one
project's specific execution of it), add it here with the same "what it's for, when to
include it" framing — the point is to grow this into a shared vocabulary, the same way
`logo-prompting`'s anti-slop guardrails grew from real jobs.
