# Logo intake checklist

Seeded from the Notion "Logo offer questions" intake structure. Use this as an interview checklist when a logo job shows up without a brand.md or existing brief already answering these — don't ask questions the brand.md already answers.

## Brand basics
- Brand/product name (exact spelling, capitalization — e.g. "Fleetline" not "Fleet Line")
- One-line description of what it does and who it's for
- Existing tagline, if any

## What the mark needs to do
- Wordmark only, mark-only (icon), or a lockup of both?
- Where will it actually appear — favicon (16px), app icon, business card, embroidered patch, letterhead, app splash screen, social avatar? Each of these has different survival constraints (a favicon needs to read at 16px; an embroidered patch can't have fine gradients; a dark-mode app icon needs to work on both light and dark backgrounds).
- Does it need a reversed/dark-mode variant? A monochrome/single-color fallback (for stamping, engraving, or single-color print)?
- Any required state variants (e.g. a "resolved" or "success" accent color that only shows up in one context, not the primary lockup)?

## Constraints
- Existing palette (hex values) or is palette open?
- Existing typography system, or open?
- Any hard no's — colors, motifs, or design moves the brand must never use? (Every brand has industry-specific clichés to avoid — ask specifically, don't assume "no gradients" covers it.)
- Does the name itself contain a visual trap — a literal word that would produce a cliché if illustrated literally? (E.g. "Fleetline" contains a radio-dispatch reference that should be a quiet wink, not a literal CB radio icon; a "Bright" naming a lightbulb; a "Shield" naming an actual shield.) Name the trap explicitly so the prompt can route around it.

## Feel
- 3-5 adjectives for how the mark should feel (grounded / unhurried / bold / playful / clinical / warm, etc.)
- Reference brands whose *visual restraint or confidence level* is right, even if their category is unrelated
- Anti-reference brands or a specific competitor's look to avoid overlapping with

## Practical
- Who is the primary audience actually looking at this mark, and in what context? (A shift worker glancing at a phone screen mid-shift reads differently than someone admiring a landing page — this changes how much detail is safe to include.)
- Any regulatory/compliance visual requirements (e.g. healthcare marks sometimes can't use a plain red cross, financial marks sometimes can't imply FDIC-style official seals)?
- Timeline / how many directions are wanted (see the structural-variety rule in the main SKILL.md — more than one direction means more than one *form*, not more than one palette)
